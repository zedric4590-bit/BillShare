# BillShare: Electricity Bill Allocation Prototype

## About
BillShare is a website prototype that estimates appliance electricity consumption and demonstrates how electricity bills can be allocated among dormitory tenants. It aims to promote transparency through usage tracking and clear billing calculations.

## Features
- Appliance Usage Tracker
- Estimated monthly electricity consumption in kWh
- Estimated electricity cost based on the entered rate per kWh
- Tenant electricity usage summaries
- Equal, consumption-based, and hybrid bill allocation methods

## How to Use
1. Open `DormShare.html` in a web browser.
2. Enter the total electricity bill and tenant information.
3. Add appliances and enter their power ratings and usage durations.
4. Review the estimated electricity consumption and costs.
5. Select a bill allocation method to view the estimated share of each tenant.

## Technologies Used
- HTML
- CSS
- JavaScript

## Limitations
BillShare is a prototype developed for research and demonstration purposes. It estimates electricity consumption using appliance power ratings and reported usage times. These estimates may differ from actual electricity consumption. The website does not directly measure electricity usage or verify actual utility bills.

## Project Status
Prototype. Features and calculations may be revised during testing and evaluation.
